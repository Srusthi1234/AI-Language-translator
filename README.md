AI Language Translator 🌐

📌 Project Overview

AI Language Translator is a simple web-based application that translates text from English to Kannada using Artificial Intelligence and Natural Language Processing (NLP). The project uses a Python Flask backend and a simple HTML, CSS, and JavaScript frontend.

🎯 Objectives

- To develop a simple AI-based language translation system.
- To translate English text into Kannada.
- To understand the use of NLP and Transformer models.
- To create a user-friendly web interface.
- To connect the frontend with a Python Flask backend.

🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Hugging Face Transformers
- PyTorch
- NLP (Natural Language Processing)

🚀 How to Run the Project

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_LINK

2. Open the project folder

cd AI-Language-Translator

3. Install the required libraries

pip install -r requirements.txt

4. Run the Flask application

python app.py

5. Open the application

Open your browser and visit:

http://127.0.0.1:5000/

💡 How It Works

1. The user enters English text in the input box.
2. The text is sent to the Flask backend.
3. The Transformer-based NLP model processes the text.
4. The translated Kannada text is returned.
5. The result is displayed on the web page.

📷 Project Output

The application provides a simple and colorful interface where users can enter English text and receive the Kannada translation.
